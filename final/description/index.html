Final Description

Handshake post feature: see it in feed on Handshake!

Must be logged in to view (free account), this description is specifically for a longer post needing the "read more" feature.

TRIGGERS

Handshake Post Container

More/Less Button

  1. Hover On "...More"
  2. Hover Off "...More"
  3. Click "...More"
  4. Hover On "...see less"
  5. Hover Off "...see less"
  6. Click "...see less"

Heart Button

  1. Hover On the heart icon
  2. Hover Off the heart icon
  3. Click the heart icon

Bookmark Button

  1. Hover On the bookmark icon
  2. Hover Off the bookmark icon
  3. Click the bookmark icon

Comment Button

  1. Hover on comment icon
  2. Hover off comment icon
  3. Click comment icon

Post Contents

  1. Hover On the content in the post
  2. Hover Off the content in the post

Rules

More Button

Hover On

  1. The "...more" button will linearly ease through a gradient in 0.4s on hover
  2. The "...see less" button will linearly ease through a gradient in 0.4s on hover
  3. Cursor becomes pointer

Hover Off

  1. The "...more" button will linearly ease back to a solid color (#062326)
  2. The "...see less" button will linearly ease back to a solid color (#062326)
  3. Pointer returns to cursor

Click

  1. The caption will expand on the top of the post, image connected with post will shift downward giving more room for the now elongated caption. The "...more" button disappears. The "...see less" button appears.
  2. The caption will move back upwards, image shifts upward to its orginal state. The "...see less" button dissappears. The "...more" button reappears.

Heart Button

Hover On

  1. Heart icon eases in from white into a dark teal, #062326, in 0.4s
  2. Cursor becomes pointer

Hover Off

  1. The heart icon eases back into a white fill in 0.4s
  2. Pointer returns to cursor

Click

  1. Heart icon eases into a pink fill within 0.4s

Bookmark Button

Hover On

  1. Bookmark icon eases in from white into a dark teal, #062326, in 0.4s
  2. Cursor becomes pointer

Hover Off

  1. The bookmark icon eases back into a white fill in 0.4s
  2. Cursor becomes pointer

Hover On

  1. The bookmark icon returns to its original state
  2. Pointer returns to cursor

Click

  1. Bookmark icon eases into a purple fill within 0.4s

Comment Button

Hover On

  1. Comment icon eases in from white into a dark teal, #062326, in 0.4s
  2. Cursor becomes pointer

Hover Off

  1. The comment icon eases back into a white fill in 0.4s
  2. Pointer returns to cursor

Click

  1. Comment icon eases into a green fill within 0.4s
  2. Comment box fades in from under the row of buttons

Post Content

Hover On

  1. Cursor becomes pointer
  2. A green drop shadow eases in, illuminating the card within 0.4s

Hover Off

  1. Green shadow fades out in 0.4s
  2. Pointer returns to cursor
  3. Card returns to its orginal state
